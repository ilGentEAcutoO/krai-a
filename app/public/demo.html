ไม่ชัวร์? AI รับฝากข้อความไว้ให้ลูกตัดสิน

เดโมด้านบนจำลองขั้นที่ 2–4 และผลลัพธ์: เสียงและคำตัดสินบันทึกจากการรันระบบจริง ไม่ใช่สคริปต์ที่แต่งผลไว้

5 เคสทดสอบ และอีกหนึ่งเคสที่คุณเป็นคนโทร

มุกแอบอ้างคลาสสิก 3 แบบ หนึ่งสายจริงที่ต้องไม่โดนตัด และหนึ่งสายกำกวม แตะเคสเพื่อฟังในโทรศัพท์ด้านบน

สด · 2 นาที คุณเป็นมิจฉาชีพ

โทรเข้าด้วยไมค์ของคุณ AI ตัวเดียวกันรับสาย ลองหลอกให้ได้ แล้วดูคำตัดสิน

ตอนนี้คุยสดเต็มแล้ว — ลองฟังเคสตัวอย่างก่อนนะ

เบื้องหลัง: หนึ่งสาย ผ่านอะไรบ้าง

AI สองตัวแบ่งงานกัน ตัวหนึ่งคุย อีกตัวตัดสิน เซิร์ฟเวอร์รันบน Cloud Run

สายเข้า มือถือแม่ → โอนสาย เบอร์กลางรับสายผ่าน Twilio
Cloud Run เซิร์ฟเวอร์สายเสียง Node + WebSocket สตรีมเสียงสองทาง ขยายตามจำนวนสาย
Gemini คุยและพูดเป็นเสียง Gemini Live ฟัง ถาม และตอบเป็นภาษาไทย
Jev ผู้ตัดสินทุกประโยค ให้คะแนน มิจ / คนจริง / ไม่ชัวร์ พร้อมเหตุผล
Firebase · Firestore บันทึกสายและคำตัดสิน Firestore ผ่าน Firebase Admin SDK บน Cloud Run · เดโมใช้เอกสารของตัวเอง ไม่แตะข้อมูลสมาชิก (ตัวผลิตภัณฑ์: ข้อมูลครอบครัว)
